# Hamilton 低预算 VIV 端到端冒烟测试

本次运行只验证 Hamilton SR Agent 的端到端链路是否可用，不追求科研质量，也不得形成正式研究结论。

## 硬性限制

1. 只读取 `task.md` 和 `input/U248_train.csv`。
2. 不得读取任何 `*_test.csv` 或 OOD 文件。
3. 从训练轨迹按时间顺序最多取 2,000 行；内部验证集必须是末尾的连续时间块。
4. PySR 必须使用 `max_evals <= 200`，并同时设置 `niterations <= 5`、`populations <= 4`、`population_size <= 12`。
5. 不得把任务替换成合成数据、多项式示例或其他基准。
6. 只需获得至少一个候选加速度方程，并报告训练集与内部验证块的基础指标。
7. 对最优候选只进行一次短时 ODE 积分，用于检查积分接口是否可运行；不要求复现长期极限环。
8. 必须更新 `history/round1/trace.md`、`plan.md` 和 `findings.md`。
9. 最后必须调用 `finish`，明确说明这是 smoke test，以及成功和失败的链路环节。

## 成功标准

- 能读取指定训练数据；
- 能实际调用一次 PySR；
- 能保存候选方程和基础指标；
- 能尝试一次 ODE 积分并记录结果；
- 能完成 L1/L2 记录和结构化结束信号。
